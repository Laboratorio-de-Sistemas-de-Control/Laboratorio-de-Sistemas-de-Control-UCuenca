# Robot LEGO MINDSTORMS EV3

El **bloque EV3** es el "cerebro" del sistema LEGO MINDSTORMS: una unidad programable que controla motores, lee sensores (giroscopio, color, ultrasonido y contacto) y se comunica por Bluetooth, Wi-Fi o USB. Se usa como introducción a la robótica y a la programación.

## Cuidado del kit

- Maneja el bloque EV3 con cuidado: es la parte más costosa del kit.
- Al terminar, desarma el robot y devuelve todas las piezas al kit.
- Si una pieza se pierde o se daña, avisa al personal del laboratorio.
