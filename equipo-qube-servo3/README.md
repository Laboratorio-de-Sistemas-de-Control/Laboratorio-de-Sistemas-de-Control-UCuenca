# QUBE-Servo 3 (Quanser)

El **QUBE-Servo 3** de Quanser es una plataforma portátil de servomotor para enseñar control y mecatrónica. Tiene un motor DC de accionamiento directo, dos encoders, un sistema de adquisición de datos y un amplificador integrados, y se conecta al computador por USB. Viene con un **disco de inercia** y un **péndulo rotatorio** (péndulo invertido), que se acoplan con imanes. Se usa en las prácticas de la asignatura de Robótica.

## Datos del equipo

| Característica | Valor |
|---|---|
| Fabricante / modelo | Quanser / Qube-Servo 3 |
| Motor | DC de accionamiento directo, 24 V |
| Encoders | 2048 cuentas por vuelta en cuadratura (motor y péndulo) |
| Dimensiones y peso | 10,2 × 10,2 × 11,7 cm; 1,083 kg |
| Interfaz | USB |
| Software | MATLAB/Simulink con QUARC; interfaces de Quanser para Python y C/C++ |

⚠️ **Por confirmar:** cantidad de equipos, ubicación en el laboratorio y persona responsable.

## Seguridad

- Las piezas giratorias están expuestas: mantén manos, cabello y objetos lejos mientras el motor está activo.
- Usa **solo la fuente, el cable y las piezas originales**, y conecta el equipo a una toma con tierra.
- Uso solo en interiores y por personal técnicamente calificado.
