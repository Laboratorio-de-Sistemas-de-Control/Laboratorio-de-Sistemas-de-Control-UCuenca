# Equipos del Laboratorio de Sistemas de Control

Guías y documentos de los equipos del **Laboratorio de Sistemas de Control** de la Universidad de Cuenca. Aquí encuentras los manuales y
las guías de cada equipo para consultarlos antes de usarlo.

Cada equipo tiene su propia carpeta, con un `README.md` que explica qué es, sus datos principales, las normas de seguridad y los documentos
en PDF.

## Equipos disponibles

| Equipo | Para qué sirve | Carpeta |
|---|---|---|
| **Fresadora de PCB Prometheus** (Zippy Robotics) | Fabricar placas de circuito impreso: fresado de pistas, taladrado y corte del contorno | [equipo-cnc](equipo-cnc/README.md) |

## Cómo está organizado

```text
edu-equipos/
└── equipo-<nombre>/
    ├── README.md   ← qué es el equipo, datos, seguridad y uso básico
    └── Docs/       ← PDF numerados por prioridad (01_..., 02_...)
```

Los PDF de cada carpeta van numerados por prioridad: empieza por el `01_`.

## Antes de usar un equipo

- Lee la sección de **seguridad** del README del equipo y el manual del fabricante (`01_...`).
- Si no sabes usar un equipo, pide autorización al personal del laboratorio antes de operarlo.

## Notas

- Los manuales son de los fabricantes. Para la versión más reciente, usa el enlace oficial que aparece en el README de cada equipo.
- Los datos marcados con `⚠️ por confirmar` todavía no están verificados.
